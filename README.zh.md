# Google 搜索广告品牌词竞价研究

[English](README.md)

基于 Google 官方公开广告存档整理的**Google 搜索广告与品牌词竞价**的公开数据和实用材料。适合被人抢品牌词的品牌方、研究竞争对手的投手，以及需要可引用数字的人。

## 里面有什么

| | 内容 | 适合谁 |
|---|---|---|
| [**取证材料包**](evidence-kit/README.zh.md) | 一份能被受理的品牌词投诉要有什么、逐项取证清单、改几个字就能发的下架通知 | 品牌方、法务、渠道管理 |
| [**一条 Google 搜索广告能活多久？**](research/2026-10-ad-lifespan/README.zh.md) | 40 万条广告的研究：新广告一半活不过四个月左右，但你今天看到的广告，一半已经跑了快两年。附 CSV 数据 | 投手、分析师、需要引用数据的人 |
| [**方法说明**](METHODOLOGY.zh.md) | 数据从哪来、每个字段什么意思、说明不了什么 | 所有用这些数据的人 |

## 关键数字

来自[广告寿命研究](research/2026-10-ad-lifespan/README.zh.md)，2026-10-12 抽样：

- 新上线 Google 搜索广告的寿命中位数：**121 天**
- 7 天后仍在投放：**92.4%** · 30 天：**74.7%** · 180 天：**40.2%**
- 现在正在展示的广告，已投放时长中位数：**686 天**
- 样本内广告数 100 条以上的广告主，新广告寿命中位数 **185 天**；小广告主约 65 天

## 这里不提供什么

- **没有花费和出价数据。** Google 存档里没有，任何号称能告诉你竞争对手关键词花费的数字，都是模型估的。
- **没有单个广告主或单个域名的明细。** 研究只发布比例和分布。
- **不构成法律意见。**
